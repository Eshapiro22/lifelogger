2. Salesforce Accounts export required

In Salesforce: Reports → New Report → Accounts → add columns Account ID, Account Name, Account Owner, Website, Parent Account, Type → remove filters so it covers all accounts (not just "My accounts") → Export → Details Only, CSV, UTF-8.

Org too big to export? Generate lookup queries from your leads instead

Builds Salesforce queries that fetch only the accounts whose names resemble the companies in your lead list, so the result is a few hundred rows instead of the whole org. Paste the prompt into a Claude that has your Salesforce connector (or run the queries yourself), save the result as a CSV, and load it above with the "only my accounts" box unticked.

3. Salesforce Contacts export optional

Tells you which leads already exist in Salesforce and who owns the contact. Report on Contacts & Accounts with columns Contact ID, First Name, Last Name, Account Name, Contact Owner, Title, Email.
